# User Portal (Frontend Micro-Frontend)

React + TypeScript frontend client application for `user-service`.
Integrated with the **DevEx AI Code Review** automated platform.

## Architecture
- **Framework**: React 18 + Vite + TypeScript 5
- **Testing**: Vitest
- **Code Review Policies**: Documented in [`CR.md`](./CR.md)
- **CI / AI Review**: Managed via `.github/workflows/ci-and-ai-review.yml`

## Getting Started
```bash
npm install
npm run dev
npm run test
npm run lint
```
